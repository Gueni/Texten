

# PyPLECS
![python3.x](https://img.shields.io/badge/python-3.x-brightgreen.svg)

PyPLECS is a play on words of Python & PLECS, signifying the interconnection between the two platforms. PyPLECS aims to be the ultimate simulation platform. The goal is to create an automated and scripted power electronics simulation toolchain that combines the five P's, pre-processing of raw data, simulation processing, and post-processing of results for viewing. All in an easy-to-use package utilizing state-of-the-art programs, models, math and code. This documentation page serves as the first entry points for users and future developers alike. Please enjoy, and remember: feedback is always welcome!
